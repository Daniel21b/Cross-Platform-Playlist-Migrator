🚀 HOW TO USE YOUR APP
═══════════════════════════════════════════════════════════════════

1. OPEN BROWSER
   http://localhost:3000

2. CONNECT SPOTIFY
   Click "Connect to Spotify"
   → Login and authorize
   → Returns with "Connected" ✅

3. SET UP YOUTUBE MUSIC (ONE-TIME)
   Terminal:
     cd python-service
     python3 -m venv venv
     source venv/bin/activate
     pip install -r requirements.txt
     python3 auth_setup.py
   
   Browser:
     Refresh page
     → Shows "Connected" ✅

4. MIGRATE PLAYLISTS
   • Select source platform
   • Choose playlist
   • Select destination
   • Click "Start Migration"
   • Watch progress!
   • Get link to new playlist
